# Unreal first playable slice

The Unreal runtime source and `tools/bootstrap_unreal.py` now exist. They have not been compiled or executed in the editor: Unreal is still downloading and the supported Windows C++ compiler needs installation. No `.uasset` map, engine import, Android package or device test has been completed.

Once the engine and C++ tools are ready, run `tools/launch_unreal.ps1 -Build -Bootstrap -Launch` from the workspace. The tool records the installed engine version. Bootstrap uses Unreal editor APIs to create `/Game/Mechalord/Maps/Entry`, painted unlit materials, commander assets, five editable stage timelines and chunk labels. It writes an import receipt to `builds/unreal-bootstrap.json` only when actually executed in the editor.

The initial visual slice uses the faithful 19,537-triangle TRELLIS commander source with its preserved 1,024-pixel painted texture. This temporary first-view choice exceeds the planned 4,000-triangle shipping target. The separate mobile skeletal candidate and Idle/Run clips are imported for review. `AMechalordCommanderPawn.bUseSkeletalCommander` defaults to false; enable it in a pawn subclass after examining the joints, texture alignment and orientation. Skeletal geometry is not claimed approved.

The latest local environment and troop visuals were rejected or remain unapproved. Bootstrap leaves them out by default. Primitive track, troop and gate meshes permit mechanic validation. Set `MECHALORD_EXPERIMENTAL_ART=1` only to import the existing kit for internal tests; this does not grant visual acceptance.

In Play, choose **Relic Causeway**. The first `+10` gate crosses after four seconds. Horizontal touch or mouse dragging steers within the middle play area; A/D or Left/Right also steer. Space activates the equipped relic, E deploys a charged champion during a siege, Escape toggles pause and R retries after a result. The UI offers the same actions, stage replay, upgrades and relic selection. The fixed-step battle core produces automatic combat, gate arithmetic, reserve transfer, launcher packets, win and defeat. The controller creates one HUD and the mode records each run result once. Suspension pauses the battle until the player resumes.

Crowds use two fixed instance buffers with at most 80 combined visible representatives; logical troops and combat stay in the shared simulation. Instances, labels and reusable track sections are pooled across retries. Experimental authored narrowing constrains the player lane in the engine adapter. This does not change the standalone battle core.

Stages four and five require an installed compatible chapter and successfully loaded authored stage assets. Their optional references are soft. They cannot start using the inline fallback timeline if the chapter content is missing. Base assets/materials have a higher-priority chunk-0 label; the optional chapter has chunk 1001. Chunk assignments and the final pak contents still require an actual cook audit.

Required editor checks are: UHT/build diagnostics; Entry startup; camera framing and Android touch hit areas; FBX metre-to-centimetre scale and facing; source UV/material match; skeletal animation deformation; first gate applies once; all three base runs can win, lose and retry; troop counts survive the siege transition; pause/resume; imports and instances do not accumulate across retries. Next, cook Android through Turnkey, inspect chunk placement and sizes, and run the Nothing Phone (3) 20-minute measurement. The asset target, size ceilings and sustained 30 fps remain unverified.

Bootstrap APIs were checked against Epic's [DataAssetFactory](https://dev.epicgames.com/documentation/en-us/unreal-engine/python-api/class/DataAssetFactory), [LevelEditorSubsystem](https://dev.epicgames.com/documentation/en-us/unreal-engine/python-api/class/LevelEditorSubsystem), [MaterialEditingLibrary](https://dev.epicgames.com/documentation/en-us/unreal-engine/python-api/class/MaterialEditingLibrary), [PrimaryAssetLabel](https://dev.epicgames.com/documentation/en-us/unreal-engine/python-api/class/PrimaryAssetLabel), [PrimaryAssetRules](https://dev.epicgames.com/documentation/en-us/unreal-engine/python-api/class/PrimaryAssetRules) and [FBX import UI](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Editor/UnrealEd/UFbxImportUI) documentation. Local engine execution remains the acceptance check.

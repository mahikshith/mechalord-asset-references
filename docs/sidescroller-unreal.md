## Project layout

- `game/SideAssault` — created from UE 5.8's C++ Third Person template (all variants) by `tools/unreal/instantiate_template.py`; default map `Variant_SideScrolling/Lvl_SideScrolling`. Template content folders (Characters, Input, LevelPrototyping) are regenerated by that script, not committed.
- Our code: `Source/SideAssault/IronLegion/`
  - `AIronTrooper` (extends the template's `ASideScrollingCharacter`): 8-way aim, held auto-fire, crouch (plants you), melee, swim dive (invulnerable when submerged), health with hit recovery, free checkpoint respawn, rifle prop on `hand_R`, camera distance, profile stance yaw when standing. Combat input actions are created in code (J/LMB fire, W aim up, S/Ctrl down, K/RMB melee + gamepad).
  - `AIronProjectile`: plane-constrained tracer round, point damage, physics impulse.
  - `UIronAnimInstance`: native pose evaluation (no anim graph asset) from retargeted Manny clips.
  - Autopilot/capture flags: `-IronAutopilot -IronCapture=<dir>`, `-IronPoseLab`, `-IronZoom=`, `-IronGrip=P,Y,R,X,Y,Z`, `-IronStanceYaw=`, `-IronBones`, `-IronNoAnim`, `-IronAnimTest=<asset>`.
- Our content: `Content/IronLegion/` (hero mesh, textures, M_IronHero, IK rigs, retargeter, retargeted anims, BP_IronTrooper, rifle prop).

## Pipelines

1. Hero export: `blender -b --factory-startup -P tools/blender/export_soldier.py -- MilitarySkin Head3 game/SideAssault/Import/Soldier` (bakes Unity specular maps to BaseColor/ORM/DirectX normal; bones in cm with an unscaled root — required, otherwise retargeted root motion is ×100).
2. Import + retarget: `UnrealEditor-Cmd.exe <uproject> -run=pythonscript -script=tools/unreal/import_hero.py -unattended -nosplash` (adds Spine/Neck/Head chains by hand because rigify names are not auto-detected).
3. Blueprint: `tools/unreal/setup_hero_blueprint.py` (BP_IronTrooper = BP_SideScrollingCharacter reparented to AIronTrooper, native anim class, set as the side-scrolling game mode's pawn). Python `unreal.Rotator` takes (roll, pitch, yaw) — use keywords.
4. Captures: `tools/unreal/capture_autopilot.ps1 -Out <dir>` (frames + contact sheet + GIF), `tools/unreal/pose_lab.ps1` for close-up stills.
5. Build: `Engine/Build/BatchFiles/Build.bat SideAssaultEditor Win64 Development -Project=<uproject> -WaitMutex`.

## Pitfalls found

- The retargeted template anim blueprint vanished the mesh (×100 root scale) and its foot-IK control rig does not match the soldier hierarchy; the native anim instance replaces it.
- Hand bones carry a tiny import scale: attached props must use absolute scale.
- Changing `additive_anim_type` on the aim poses from Python crashed the editor; the anim instance applies them as mesh-space additives instead.
- Don't run `Remove-Item` on a variable path in this harness; use fresh folder names.

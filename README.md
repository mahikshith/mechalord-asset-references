# Mechalord original asset references

Original concept images for Mechalord, an independent medieval-mech battle game.

These images are the required visual references for 3D production. They are not downloadable 3D models. Preserve the armor shapes, body proportions, weapons, palette and painted surface details during conversion.

- `relic-marshal-v1.png`: armored commander
- `gearling-sentinel-v1.png`: wheeled allied troop
- `rust-crawler-v1.png`: tracked enemy

The simplified experimental Blender blockouts were rejected and are deliberately excluded from this reference package.

Images were generated for this project using OpenAI Image Generation. Original asset references are published here by the project owner to provide stable image URLs for the requested conversion workflow. No other game's assets are included.
